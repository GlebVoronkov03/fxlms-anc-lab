# Протокол: Q-12M + Boya BY-M1 + Maono AU-402L

Дата: 2026-08-30.  
Запуск: `python_proto/run_hardware_compare.bat`  
Записи: `python_proto/measurements/hardware_compare/`

Цель: оставить **одну** пару микрофонов и решить, годится ли Q-12M как синхронный двухканальный вход для ANC.

## Что заказано

| Устройство | Суть | Для ANC важно |
|---|---|---|
| **Q-12M** | 2-канальный USB-микшер / внешняя карта, 16 бит / 48 кГц, фантом 48 В, Stereo/Mono | Input 1 → L, Input 2 → R без смешивания; HPF выкл; задержка как можно ниже |
| **Boya BY-M1** ×2 | Всенаправленный электрет, 65 Гц–18 кГц, −30±3 дБ, S/N 74 дБ, 6 м, 3.5 мм TRRS, LR44 | Режим **Camera**, своё питание, переходник 3.5→6.35 TS |
| **Maono AU-402L** ×2 | Всенаправленный электрет, 50 Гц–18 кГц, −30 дБ, S/N 74 дБ, 2 м, 3.5 мм TRRS, **без батареи** | Только plug-in power. На входе 6.35 мм Q-12M питания часто нет — пара может молчать |

48 В фантомное питание **не заменяет** plug-in power и для этих петличек должно быть **выключено**.

## Подключение один раз

1. Не выбрасывать упаковку до конца проверки.
2. Q-12M → USB ноутбука.
3. На микшере: **Stereo**, **48V OFF**, **HPF/80 Hz OFF**, эквалайзер в ноль, эффекты выкл.
4. В Windows выбрать Q-12M как микрофон. Формат 2 канала / 48 кГц. Эффекты Windows выкл.
5. Сначала тестировать **Boya** (выше шанс, что вход 6.35 мм заработает).
6. Потом сменить только кабели на **Maono**, микшер не трогать.
7. Gain обоих каналов одинаковый. Речь около −30…−12 dBFS.

## Порядок тестов в GUI

Для **каждой** пары, режим Stereo:

1. Живые уровни — убедиться, что оба капсюля живые.
2. Тишина / шум — 8 с.
3. Микрофон 1 (вход 1 / L) — 8 с.
4. Микрофон 2 (вход 2 / R) — 8 с.
5. Маршрут 1 → пауза → 2 — 12 с.

Один раз для микшера, любой рабочей парой:

6. Задержка микшера (клик) — наушники/колонки в выход Q-12M, микрофон 1 у динамика.

Необязательно: те же тесты 3–4 в режиме **Mono**. Ожидание: каналы схлопнутся. Потом сразу вернуть Stereo.

## Как читать вывод

Пара годится, если:

- в тесте 1 левый канал громче ≥15 дБ;
- в тесте 2 правый громче ≥15 дБ;
- в маршруте баланс меняет знак (сначала +, потом −).

Микшер годится, если хотя бы одна пара это показала **и** задержка не катастрофическая:

- ≤8 мс — нормально для стенда;
- 8–20 мс — только низкие частоты;
- >20 мс — для активного подавления слабо, карту лучше возвращать.

Если **обе** пары дают одинаковое дублирование L=R — виноват Q-12M.  
Если Boya разделены, а Maono молчат — оставлять Boya, микшер не браковать.

После тестов обеих пар GUI сам пишет рекомендацию внизу окна и в  
`python_proto/measurements/hardware_compare/latest_recommendation.txt`.
