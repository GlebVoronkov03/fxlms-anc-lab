# Аппаратный комплект для двухканального ANC-стенда

Дата проверки: 2026-08-23. Бюджет: до 5 000 ₽.

## Рекомендация: TEYUN Q-12 + 2× Maono AU-100

### 1. Один аудиоинтерфейс TEYUN Q-12

Поиск Ozon:

https://www.ozon.ru/search/?text=TEYUN%20Q-12%20USB%20%D0%B0%D1%83%D0%B4%D0%B8%D0%BE%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81

Ориентир цены: 1 100–2 100 ₽, но цена и продавцы меняются.

Обязательные признаки карточки/фото:

- точная модель `TEYUN Q-12`, не V8/V10 и не детские часы Q12;
- два физических входа `INPUT 1` и `INPUT 2`;
- XLR + 6.35 мм для обоих входов;
- физический переключатель `MONO / STEREO`;
- USB-подключение к ПК;
- USB recording `2 input / 2 output`, 16 bit / 48 kHz;
- возврат товара разрешён.

Почему подходит:

- в режиме `STEREO` Input 1 передаётся в левый USB-канал, Input 2 — в правый;
- оба канала оцифровываются одним устройством и имеют общие часы;
- USB class compliant, Windows/Linux;
- 48 кГц достаточно для FxLMS;
- обзор с измерениями указывает полосу примерно от 13 Гц, если HPF выключен.

Ограничения:

- 16 бит;
- нет фирменного ASIO — реальную WASAPI/WDM-KS latency обязательно измерить;
- предусилители шумнее дорогих интерфейсов;
- заявленные 48 В фактически могут быть около 35 В;
- **HPF 80 Hz должен быть выключен**, иначе он удалит нужный для ANC низ.

### 2. Два одинаковых Maono AU-100

Поиск Ozon:

https://www.ozon.ru/search/?text=Maono%20AU-100

Количество: **2 штуки одной ревизии и желательно одного продавца**.

Ориентир цены: 1 000–1 500 ₽ за штуку.

Обязательные признаки:

- точная модель `Maono AU-100`, не беспроводной комплект;
- батарейный блок;
- всенаправленный electret condenser;
- диапазон, заявленный около 15/20 Гц – 18 кГц;
- в комплекте переходник 3.5 мм → **6.35 мм TS**;
- кабель около 6 м;
- батарея и возможность возврата.

Подключение:

- AU-100 №1 через штатный 6.35-мм адаптер → Q-12 Input 1;
- AU-100 №2 → Q-12 Input 2;
- питание микрофонов от собственных батарей;
- `48V` на Q-12 **выключить**;
- Q-12 поставить в `STEREO`;
- оба gain начать с минимума и выровнять тестовым источником.

Ориентир суммы: 1 100–2 100 + 2×(1 000–1 500) = **3 100–5 100 ₽**.

## Перед оплатой

Ozon показывает anti-bot автоматическому браузеру, поэтому конкретные карточки, остатки и цены не удалось надёжно открыть. Нельзя выбирать только по заголовку продавца.

Перед покупкой прислать ссылки или скриншоты выбранных карточек. Проверить:

1. фото передней и задней панели Q-12;
2. наличие переключателя Stereo;
3. комплектацию каждого AU-100 переходником 6.35 мм;
4. отзывы с Windows 10/11;
5. возможность возврата после проверки каналов.

## Что не покупать

- два отдельных USB-микрофона — независимые часы и дрейф;
- пассивный «объединяющий» Y-адаптер — суммирует микрофоны;
- V8/V10 live sound card — обычно микширует входы до USB;
- обычную дешёвую USB-карту «наушники + микрофон» — mic input почти всегда mono;
- TEYUN Q-12 без физического Stereo mode;
- комплект BM-800 без подтверждённых двух раздельных USB-каналов.

## Проверка сразу после получения

1. Не выбрасывать упаковку.
2. Подключить только Q-12, выбрать Stereo, HPF off, 48V off.
3. Запустить `python_proto/run_microphone_test.bat`.
4. Проверить, что устройство видно как 2 ch / 48 kHz.
5. Выполнить A и B: при воздействии на микрофон 1 должен доминировать L, на микрофон 2 — R, желательно ≥15 dB.
6. Измерить round-trip latency до окончания срока возврата.

Если Q-12 отдаёт моно независимо от положения Stereo либо задержка неприемлема, оформить возврат, а не адаптировать код под неподходящее железо.
