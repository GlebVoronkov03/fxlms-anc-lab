# Тест BOYA BY-M1DM без консоли

## Как открыть

Дважды щёлкнуть:

`C:\anc_project\python_proto\run_microphone_test.bat`

Откроется окно **QuietRadius — тест микрофона**. Консоль не нужна. Программа ничего не воспроизводит, поэтому акустической обратной связи не будет.

Все WAV, JSON и сводная таблица сохраняются локально:

`C:\anc_project\python_proto\measurements\microphone_tests`

## Что уже проверено автоматически

На 2026-08-23:

- `External Mic (Realtek(R) Audio)` активен и является входом Windows по умолчанию.
- WASAPI видит его как **2 канала / 48 кГц**.
- Формат float32, 2 канала, 48 кГц поддерживается.
- PortAudio сообщает nominal low input latency **3 мс**. Это заявленная задержка API, не измеренный акустический round-trip.
- Доступ Windows к микрофону разрешён.
- Для endpoint `External Mic` реестр Windows содержит `Disable SysFx = 1`: системные аудиоэффекты помечены отключёнными.
- Уровень/boost нельзя надёжно определить через публичный Windows API. В приложении есть кнопка **«Открыть настройки звука»**.
- DroidCam виден как один канал / 16 кГц; для realtime ANC он не используется.

Не менять реестр вручную. Интерфейс только читает настройки и открывает штатные страницы Windows.

## Перед тестом

1. Закрыть Discord, Telegram, браузерные звонки, диктофон и другие приложения с микрофоном.
2. Подключить BOYA напрямую, без лишнего переходника, если разъём совместим.
3. В Windows открыть настройки звука кнопкой интерфейса:
   - выбрать `External Mic (Realtek(R) Audio)`;
   - формат 2 канала, 48 кГц;
   - улучшения звука выключены;
   - начать с усиления **0 дБ**, не +10 дБ;
   - пространственный звук и mono audio выключены.
4. Для `OFF/Smartphone` батарейное питание не требуется.
5. Для `Camera` установить свежую LR44 правильной полярностью. Начинать с низкого уровня: этот режим рассчитан на camera/recorder input и может не соответствовать combo-jack ноутбука.

## Обязательный протокол

Выполнить сначала весь набор в `OFF/Smartphone`, затем повторить в `Camera`.

### 1. Тишина / собственный шум

- Положить оба капсюля рядом на мягкую поверхность.
- Не касаться стола, молчать 8 секунд.
- Нажать **Старт**; тест завершится автоматически.

Что проверяем: шумовой фон, DC offset и отсутствие перегрузки.

### 2. Капсюль A

- Капсюль B завернуть в мягкую ткань, не сдавливая провод.
- Говорить в 2–3 см только от A или легко постукивать рядом с ним.
- Выбрать `Капсюль A — изоляция канала` и нажать **Старт**.

### 3. Капсюль B

- Поменять капсюли местами: A изолировать, воздействовать только на B.
- Запустить соответствующий тест.

### 4. Проверка дублирования

- Первые 4 секунды воздействовать только на A.
- Затем 2 секунды ничего не делать.
- Последние 4 секунды воздействовать только на B.

Интерфейс завершит запись через 10 секунд.

## Как читать таблицу

- **RMS L/R** — средний уровень каналов в dBFS. Ближе к 0 — громче.
- **Корреляция**:
  - почти `1.000` при одинаковых уровнях — каналы дублируются;
  - меньшее значение само по себе не доказывает разделение, поэтому нужны тесты A и B.
- **Разделение** — разница RMS между каналами:
  - `≥15 дБ` — достаточно для первого стенда;
  - `6–15 дБ` — слабое разделение/crosstalk, повторить;
  - `<0.2 дБ` вместе с корреляцией `>0.9995` — практически моно-копия.
- **Перегрузка** — уменьшить уровень/boost и повторить.

Окончательный признак независимых каналов:

1. в тесте A доминирует один канал минимум на 15 дБ;
2. в тесте B доминирует **другой** канал минимум на 15 дБ;
3. каналы не являются побитно одинаковыми.

Если в обоих режимах L/R одинаковы, сигнал суммируется до Python. Тогда не надо покупать два отдельных USB-микрофона: их часы будут расходиться. Для ANC нужен один синхронный двухканальный USB-аудиоинтерфейс.

## Безопасность и усталость

- Тест не требует громких звуков. Обычной речи или лёгкого постукивания достаточно.
- Не включать колонки во время микрофонного теста.
- Можно выполнить только `OFF/Smartphone`, закрыть программу и продолжить в другой день. Результаты сохраняются после каждого теста.
