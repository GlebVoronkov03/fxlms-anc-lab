В Camera корреляция мала не потому, что капсюли уверенно разведены, а потому, что полезное воздействие почти не поднялось над двумя независимыми шумами ADC. При переходе A→B доминирующий канал не поменялся: L оставался примерно на 1.4–2 dB выше R. Независимость капсюлей **не подтверждена**.

Первая запись «тишины Camera» содержала начальный переходный сигнал, после которого последние 4 секунды опустились примерно до −52/−54 dBFS. Это дополнительно указывает на неправильный электрический режим, контакт, батарею или затухание, а не на полезную стереозапись.

## Общий вывод для ANC

Текущая связка `BOYA → Realtek WASAPI External Mic` непригодна как reference + error:

- `OFF/Smartphone` даёт одну моно-сумму, продублированную в L/R;
- `Camera` при gain 0 dB не даёт достаточного полезного сигнала для определения каналов.

Это объясняет существенную часть неработоспособности прежнего FxLMS: алгоритм не получал два независимых физических измерения.

## Один необязательный контрольный тест

Не выполнять сегодня, если устали. Он нужен только чтобы проверить, можно ли обойти WASAPI-mix без покупки оборудования.

1. Свежая LR44, режим `Camera`.
2. В Windows временно +10 dB.
3. В GUI выбрать:
   `Mic in at front panel (black) | Windows WDM-KS` (обычно index 28).
4. Выполнить только `Проверка дублирования L/R`.
5. Говорить/стучать тише, чтобы peak был ниже −6 dBFS.

Проверка программы показала, что WDM-KS input 28 поддерживает 2 канала / 48 кГц.

Если и там нет смены доминирующего канала при A→B, контрольный путь закрывается: потребуется один синхронный двухканальный USB-аудиоинтерфейс. Два независимых USB-микрофона не покупать из-за дрейфа часов.

## Финальный аппаратный вывод

Дополнительные тесты завершены; повторять их не нужно.

- `OFF/Smartphone / WASAPI`: одна моно-сумма, продублированная в L/R.
- `Camera / WASAPI +10 dB`: один полезный доминирующий канал + второй слабый/шумовой, без маршрутизации A/B.
- `Camera / WDM-KS +10 dB`: полезный сигнал не поднялся над шумом.

Связка `BOYA BY-M1DM → combo-jack Realtek` **не подходит** для reference/error FxLMS. Следующий шаг — аппаратный: единый синхронный интерфейс с двумя настоящими ADC-входами и два независимо подключаемых микрофона либо корректный breakout распайки BOYA, подтверждённый производителем/измерением.
